# mpv 0.41 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move AnimeWitcher's actual native mpv runtimes to exactly v0.41.0, keep libmpv headers/runtime aligned, preserve the current `gpu` renderer during migration, and keep Anime4K/media_kit behavior stable.

**Architecture:** A repository-owned integration manifest is the source of truth for target version, exact upstream header hashes, resolved media_kit package versions, and per-platform runtime provenance. Each platform is upgraded independently behind its existing media_kit boundary; headers are never switched ahead of the runtime. Existing Anime4K patches remain fail-closed and `gpu-next` is explicitly outside the migration default.

**Tech Stack:** Flutter 3.47.1, Dart, media_kit 1.2.6, media_kit_video 2.0.1, media_kit_libs_video 1.0.7, libmpv/mpv v0.41.0, Python 3 verification, Bash/Ruby CocoaPods integration, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-14-mpv-0.41-upgrade-design.md`

## Global Constraints

- Target mpv is exactly `v0.41.0`.
- Keep `media_kit 1.2.6`, `media_kit_video 2.0.1`, and `media_kit_libs_video 1.0.7` unless a verified compatibility blocker requires a focused change.
- Keep iOS deployment target at 15.0 unless the replacement runtime proves a higher floor is technically required.
- Keep renderer policy explicitly on `gpu`; do not opt into `gpu-next` in this migration.
- Do not change Anime4K presets, semantics, or native Metal routing.
- Do not mark a platform upgraded unless the binary it packages/links is verified as mpv v0.41.0.
- Header files must be the exact upstream v0.41.0 files and verified by immutable Git blob SHA.
- Platform runtime changes are separate commits and must be independently revertible.
