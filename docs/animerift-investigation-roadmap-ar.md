# تقرير التحقيق وخريطة دمج Anime Rift

تاريخ الفحص: 2026-11-02. أساس AnimeWitcher: `77e7868b2c34189b5248cb63ed5417cf6c0a2dc8` من `origin/main`. هذا مستند عمل؛ المربعات غير المحددة ليست ميزات منجزة.

## أ. الأدلة والهندسة العكسية

- **الحزمة، ثقة عالية، فحص ثابت فقط:** `aapt dump badging` على APK المحدد يظهر `com.riftapps.animerift`، الإصدار `3.13.5` والرقم 68، وmin SDK 24 وtarget 36. اسم الملف يشير إلى 3.13.13 لكنه ليس دليل الإصدار. SHA-256: `5e0cba4d9bb397a94f9809ae7344394f0efcacb31f874b02909239174f00f288`.
- **Flutter، ثقة عالية، ثابت:** `rea identify-flutter-build` يؤكد `libapp.so` و`libflutter.so` على arm64-v8a وarmeabi-v7a وx86_64، وبصمة snapshot `1ce86630892e2dca9a8543fdb8ed8e22`. لم يحدد REA إصدار Dart. لا يوجد دليل على استعادة كود Dart الأصلي. `libmpv.so` و`libmediakitandroidhelper.so` مؤشران على مكتبات تشغيل، لا إثبات لمسار تشغيل فعلي.
- **Manifest، ثقة عالية، ثابت:** أذونات الإنترنت والشبكة والتخزين والإشعارات والاستيقاظ والخدمة الأمامية والدفع؛ تسجيل WorkManager و`flutter_foreground_task` و`background_downloader` وFirebase Messaging وRemote Config وApp Check وPlay Integrity. وجود المكونات لا يثبت إعدادها الفعلي أو سياسة الخدمة. إعداد network security مشار إليه بمورد مجمع؛ لم يفك محتواه بعد.
- **الأدوات:** خادم REA MCP غير معروض في الجلسة، لكن نسخة REA 6.8.0 المحلية تعمل عبر CLI، واستُخدم `identify-flutter-build`. `aapt` و`unzip` متاحان؛ `jadx` و`apktool` غير موجودين في PATH. لم يشغل APK على جهاز، ولم تلتقط حركة الشبكة، ولم تختبر أي جلسة مصرح بها.
- **مرجع CloudStream، ثقة عالية لما ينص عليه المصدر فقط:** [`animerift.kt`](https://github.com/Abodabodd/re-3arabi/blob/main/AnimeRift/src/main/kotlin/com/animerift/animerift.kt)؛ `getMainPage` يقرأ `library/home_content` و`sections` و`items`؛ `search` يرسل نصاً إلى `library/search` ويستخدم صفحة صفرية و`hasNext`؛ `load` يقرأ `library/details/{id}` ثم `library/episodes/{id}` والتوصيات؛ `loadLinks` يقرأ المصادر والتحقق من التشغيل والرابط وحقول الجودة والترجمات والترويسات. توافق نقاط النهاية أو الترخيص غير متحقق وقت التشغيل.
- **الجلسة والتحكم في الوصول، ثقة عالية للمصدر، غير متحقق على الخادم:** المرجع يولد معلومات جهاز وintegrity اصطناعية ويسجل جهازاً ويستعمل Firebase Installations وRemote Config، ثم يستدعي التحقق من التشغيل وادعاء إعلان. لا يجوز نقل هذه الآلية: هوية جهاز مصطنعة وادعاءات إعلانية تتعارض مع متطلبات المهمة. وجود App Check في الحزمة لا يثبت أن كل طلب محمي، ولا يثبت صلاحية وصول خارجي. يلزم توثيق رسمي ووسيلة مصرح بها قبل تنفيذ عميل خدمة حقيقي أو اختبار مباشر.
- **المخططات، ثقة متوسطة:** أسماء `_id`, `title`, `main_picture`, `medium_picture`, `synopsis`, `myAnimeList_rating`, `release_year`, `genreLabels`, `episode_number`, `thumbnail`, `qualities`, `tracks`, `videoUrl`, `http_headers` مستنتجة من قارئ المرجع وليست استجابات مؤكدة. 429 يعاد مرة بعد 1.5 ثانية؛ 401/403/404 تحفز استعادة في المرجع. حدود الخدمة الفعلية، مدة الرابط، الصيغ وحقوق البث غير معروفة.
- **الميزات الأخرى:** لا يثبت المرجع دعماً للجدول أو الإحصاءات أو تقييمات المستخدم أو التعليقات أو الحساب أو المزامنة. لا تستنتج عدم وجودها في التطبيق الأصلي من غيابها في الإضافة. تصنيفها: مجهولة أو غير مدعومة في الدمج إلى حين دليل وخدمة مصرح بها.

## ج. التصميم

يعاد استخدام السجل وواجهة المزود والمشغل وDownload V2. هوية العنصر الموثوقة `(providerId, sourceId)` تبقى مرافقة له في التنقل والتخزين، مع اعتبار المعرفات القديمة غير الموسومة ملك AnimeWitcher دون كتابتها مجدداً. سجلات Rift المحلية في مساحة مستقلة دون مزامنة ضمنية. لا يسمح لمزود غير معروف بالسقوط إلى المزود النشط. تحفظ مهام التنزيل القديمة بمعرفاتها دون ترحيل إتلافي، وتتميز مهام المصدر الجديد بمعرف المصدر في هوية السجل ووجهة الملف ووصف التجديد. يحفظ الاختيار الحالي ويفصل عن فتح سجل قديم. تعطى الطلبات جيلاً أو إلغاءً؛ إظهار خطأ أو حالة غير مدعومة بدلاً من بيانات مزود آخر. بديل خلط النتائج أو تبديل حساب التخزين عالمياً مرفوض لأنه يكسر العزل والتوافق.

## و. المخاطر

تغير API أو صلاحياتها و429 وغياب عقد معلن يمنع التوافق؛ لا تستخدم هوية مصطنعة أو رموزاً مزورة أو تجاوز DRM أو مطالبات إعلان وهمية. أعظم خطر فقدان البيانات هو تغيير مفاتيح قديمة أو خلط المزامنة؛ لا ترحيل تدميرياً، واختبر سجل كل مزود وعمليات المسح والتزامن. التبديل أثناء طلب نشط أو فتح تفاصيل قديمة يسبب تسرباً؛ افصل الهوية عن الاختيار وألغ النتائج القديمة. التماثل في IDs وأسماء الملفات وتجديد الروابط خطر على التنزيلات. اختبر انتهاء الروابط، عدد الاتصالات، التراجع الشبكي وأداء الذاكرة، والاختلافات بين Android وiOS وLinux وWindows. راجع ترخيص مرجع CloudStream واعتمد أفكاراً موثقة دون نسخ غير مرخص، وحقوق المحتوى شروط الخدمة مستقلة. لا تثبت mocks صلاحية API أو حقوق التشغيل.

## ز. التحقق

اختبارات وحدات للهوية والتخزين وترحيل السجل القديم والمحللات وحالات الفشل؛ widget للتبديل والصفحات وحالة عدم الدعم؛ integration للانتقال والتبديل خلال طلب جارٍ والتشغيل المحلي؛ regression لـDownload V2 والتجديد والمزامنة والمانغا؛ `dart format` و`flutter analyze` واختبارات مركزة ثم أوسع وLinux build عند توفر الاعتمادات. استخدم GitHub Actions القائمة `ci.yml` و`preview.yml` و`release.yml` بحذر؛ تحقق iOS عبر macOS فقط. كل نتيجة محلية أو mock تصنف صراحةً، ولا تعني تحقق الربط أو البث المرخص.

## سجل التنفيذ

- جرى إعداد `PagedSearchNotifier` لتتبع اختيار مزود الأنمي، وإسقاط نتائج الطلبات الأقدم عند التبديل. اختبار بمزودين وهميين يثبت ذلك ويحافظ على مسار بحث المانغا. هذا لا يسجل Rift ولا يثبت وصولاً إلى API.
- بعد توليد مصادر Riverpod، نجحت 32 حالة اختبار من اختبارات واجهة البحث وهوية Download V2. لم تُختبر كل ميزات التنزيل ولا التوافق مع منصة iOS أو الربط الحقيقي.
